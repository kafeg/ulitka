# Про улитку

Интерактивная сказка для малышей: помоги улитке доползти по скамейке до сочного листочка.
Постучись в домик, почисти дорожку, укрой от дождя, прогони муравьёв, посчитай лучи солнца,
переберись через ветку — и улитка наестся и уснёт.

Без текста, без таймеров, проиграть нельзя.

Сделано по мотивам книжки Натальи Бочечко «Про улитку» (иллюстрации Анны Поддубной,
издательство «Амоза. Дети», 2026). Вся графика и все формулировки — свои.

## Играть
**https://kafeg.github.io/ulitka/** — открывается в любом браузере, ставить ничего не нужно.

## Запуск локально
Открыть `index.html` в браузере. Или поднять статику:

```sh
python3 -m http.server 8732
```

Панель разработчика с кнопками сцен — `index.html?dev=1`.
