# ulitka

Интерактивная сказка для ребёнка ~3 лет: улитка проснулась голодной и ползёт по скамейке к листочку,
по пути семь препятствий. Каждое препятствие ребёнок снимает жестом. Текста на экране нет,
проиграть нельзя, таймеров нет. Работает офлайн, раздаётся с GitHub Pages.

Сделано по мотивам книжки Натальи Бочечко «Про улитку» (Амоза. Дети, 2026).
⚠️ Текст и иллюстрации книги в репозиторий не попадают: своя графика и свои формулировки.

## Стек — отступление от `../../docs/stack.md`
Дефолт (TS + React + Vite) здесь мешает: игрушка должна открываться двойным кликом по `index.html`
без сборки и без сети. Поэтому — ноль зависимостей, ноль шагов сборки, обычные `<script>` без модулей
(ES-модули не грузятся с `file://`). Синтаксис современный: целевое устройство — планшет, не IE.

Графика — инлайновый SVG, всё рисуется кодом, растровых ассетов нет. Анимации — Web Animations API
и CSS. Так же, как в соседнем `pawpad`, только там `<canvas>`, а здесь SVG: сцена статичная
и состоит из форм, которые надо адресовать по отдельности.

## Как запускать
| что | как |
|---|---|
| локально | открыть `index.html` двойным кликом, либо `python3 -m http.server 8732` |
| панель разработчика | `index.html?dev=1` — кнопки сцен и переключатели зерна и дрожания |
| проверка | `sh scripts/check.sh` — `node --check` по всем `src/*.js` |
| публикация | push в `main` → GitHub Pages (Settings → Pages → Deploy from a branch, `main` / root) |

## Архитектура
```
index.html      документ, стили, слои SVG (камера, погода, подсказки), порядок скриптов
src/stage.js    STAGE — единственный источник размеров и экранной разметки
src/draw.js     U — сцена: парк, скамейка, флора, детали улитки
src/props.js    Props — предметы и погода: сор, ветка, листочек, рой, тучи, дождь, ладошка, солнце
src/hint.js     Hint — рука, показывающая жест: карточка внизу и подсказка прямо на предмете
src/sound.js    Sound — синтез WebAudio по пентатонике; звуковых файлов нет
src/snail.js    Snail — улитка как актёр: позиция, домик, мордочка, ползание, жевание
src/game.js     Game — семь препятствий, камера, готовые жесты, автопрохождение
src/main.js     загрузка и панель ?dev=1
docs/spec.md    сюжет и семь препятствий
```

**Разметка экрана — в `stage.js`, и только там.** Улитка всегда стоит на экранной координате
`SNAIL_X`, препятствие всегда внутри `ACT_X0..ACT_X1`, между ними зазор. Поэтому мировые координаты
предметов считаются ОТ точки остановки улитки (`STOP` + `OFF` в `game.js`), а не задаются руками:
иначе предметы снова начнут налезать друг на друга и на улитку.

По вертикали: парк до `PARK_B`, спинка до `BACK_B`, просвет, сиденье `SEAT_T..SEAT_B`, торец до
`EDGE_B`, ниже земля под скамейкой и полоса подсказки. Всё стоит на линии `BASE`.

Скамейка — мир шириной 5300, камера (`#cam`) едет за улиткой. Мировые координаты у сора, ветки,
муравьёв и листочка; экранные — у дождя, солнца, ладошки и подсказки. Событие переводится
в координаты через `getScreenCTM().inverse()`, обработчик один на весь `<svg>`.

Улитка живёт в `#snailWrap` (позиция) → `#snailScale` (масштаб `SNAIL_S`). Координаты внутри
локальные: подошва на `y=0`, ракушка в `translate(-30,-120)`. Прятанье в домик уменьшает всё тело
к центру ракушки, и ракушка его накрывает.

Жест — объект `{kind, hint, down, move, up, solve}` в `Game.arm`. `kind` выбирает картинку подсказки,
`hint` возвращает экранную точку для руки на предмете, `solve` проходит сцену за ребёнка.

## Правила
- **Ветка одна — `main`**, коммит и пуш прямо в неё.
- **Публичный репо:** никаких личных данных, внутренних IP, токенов. Текста книги тоже нет.
- **Никакого текста для ребёнка.** Подписи живут только в панели `?dev=1` — она для взрослого.
- **Нельзя проиграть и нельзя застрять.** Если ребёнок не справился, подсказка становится ярче,
  а через время улитка справляется сама. Никаких «неверно».
- **Ноль зависимостей и ноль сборки.** Новая библиотека → сначала подумать, как без неё.
- **Сюжет не выкидываем.** Порядок препятствий и их смысл — из `docs/spec.md`, это каркас игры.

## Грабли
- ES-модули и `fetch` не работают с `file://` — отсюда классические `<script>` и графика кодом.
- **У SVG-элементов нет свойства `hidden`** (оно объявлено на `HTMLElement`). `el.hidden = true`
  молча создаёт обычное поле объекта. Только `setAttribute('hidden','')` и `removeAttribute`,
  и правило `[hidden]{display:none!important}` в CSS должно остаться.
- **Бесконечная анимация перебивает атрибут.** Покачивание «z z z» анимировало `opacity`, и надпись
  горела даже у проснувшейся улитки. В бесконечных анимациях трогаем только `transform`.
- **CSS-трансформ в WAAPI затирает атрибут `transform`.** Предмет, расставленный через
  `transform="translate(x y)"`, от анимации улетит в начало координат. Каждый анимируемый предмет —
  в обёртке без собственного `transform`.
- **Укус вырезаем маской, а не кружком фона.** Кружок цвета доски не совпадает с реальным фоном
  и торчит за край листа.
- `feDisplacementMap` пересчитывается на всю площадь элемента: на мире шириной 5300 его вешать
  нельзя, он висит только на улитке. Статичные декорации дрожат за счёт `U.wob` при генерации.
- Внешний `<svg>` режет по вьюпорту, а не по viewBox: фон нарисован с запасом за края.
- WebAudio стартует только после жеста — `Sound.wake()` зовётся из `pointerdown`.

## Грабли рисования
- **Ровные доски в лоб читаются как забор, а не как скамейка.** Нужны спинка, просвет между спинкой
  и сиденьем, передний торец, опоры, уходящие в траву, и земля под скамейкой.
- **Палец ровно по центру кулака — неприличный жест.** Указательный идёт от левого края кулака,
  большой отставлен в сторону.
- **Случайная расстановка декораций даёт ощущение обоев.** Кусты собираются из таблицы `BUSH`,
  а не рассыпаются циклом со случайными координатами.
