# ulitka

Интерактивная сказка для ребёнка ~3 лет: улитка проснулась голодной и ползёт по скамейке к листочку,
по пути семь препятствий. Каждое препятствие ребёнок снимает жестом. Текста на экране нет,
проиграть нельзя, таймеров нет. Работает офлайн, раздаётся с GitHub Pages.

Сделано по мотивам книжки Натальи Бочечко «Про улитку» (Амоза. Дети, 2026).
⚠️ Текст и иллюстрации книги в репозиторий не попадают: своя графика и свои формулировки.

## Стек — отступление от `../../docs/stack.md`
Дефолт (TS + React + Vite) здесь мешает: игрушка должна открываться двойным кликом по `index.html`
без сборки и без сети. Поэтому — ноль зависимостей, ноль шагов сборки, обычные `<script>` без модулей
(ES-модули не грузятся с `file://`). Синтаксис современный: целевое устройство — планшет, не IE.

Графика — инлайновый SVG, всё рисуется кодом, растровых ассетов нет. Анимации — Web Animations API
и CSS. Так же, как в соседнем `pawpad`, только там `<canvas>`, а здесь SVG: сцена статичная
и состоит из форм, которые надо адресовать по отдельности.

## Как запускать
| что | как |
|---|---|
| локально | открыть `index.html` двойным кликом, либо `python3 -m http.server 8732` |
| панель разработчика | `index.html?dev=1` — кнопки сцен и переключатели зерна и дрожания |
| проверка | `sh scripts/check.sh` — `node --check` по всем `src/*.js` |
| публикация | push в `main` → GitHub Pages (Settings → Pages → Deploy from a branch, `main` / root) |

## Архитектура
```
index.html      документ, стили, разметка SVG (defs, камера, улитка), порядок скриптов
src/draw.js     U — процедурная отрисовка: доски, спираль ракушки, крапинки, след, флора, муравей
src/props.js    Props — предметы и погода: сор, ветка, листочек, рой муравьёв, дождь, ладошка,
                солнце с лучами, рука-подсказка
src/sound.js    Sound — синтез WebAudio по пентатонике; звуковых файлов в репозитории нет
src/snail.js    Snail — улитка как актёр: позиция в мире, голова наружу или в домике, ползание
src/game.js     Game — семь препятствий, камера, готовые жесты, подсказка и автопрохождение
src/main.js     загрузка и панель ?dev=1
docs/spec.md    сюжет и семь препятствий: что происходит, какой жест, что меняется на экране
```

Скамейка — один длинный мир шириной 3000. Камера (`#cam`) держит улитку на экранной
координате 330 и упирается в края мира. Мировые координаты у сора, ветки, муравьёв и листочка;
экранные — у дождя, солнца, ладошки и подсказки, иначе они уезжали бы вместе с камерой.
Пересчёт события в координаты — через `getScreenCTM().inverse()`, обработчик один на весь `<svg>`.

Система координат сцены — viewBox `1000x640`, `preserveAspectRatio="xMidYMid meet"`.
Улитка живёт в группе `#snailWrap`, её координаты локальные: подошва на `y=0`,
ракушка в `translate(-30,-120)`, голова в `#head` (прячется масштабированием к ракушке).

Карандашный вид дают два приёма: фильтр `#pencil` (feDisplacementMap) на одной улитке
и `#grain` (feTurbulence в режиме multiply) слоем поверх всей сцены. Статичные декорации
дрожат «по построению» — координаты сдвигает `U.wob` при генерации.

Жест описывается объектом `{hint, down, move, up, solve}` и ставится через `Game.arm`.
`hint` возвращает экранную точку для руки-подсказки, `solve` проходит сцену за ребёнка.

## Правила
- **Ветка одна — `main`**, коммит и пуш прямо в неё.
- **Публичный репо:** никаких личных данных, внутренних IP, токенов. Текста книги тоже нет.
- **Никакого текста для ребёнка.** Подписи живут только в панели `?dev=1` — она для взрослого.
- **Нельзя проиграть и нельзя застрять.** Если ребёнок не справился, подсказка становится ярче,
  а через время улитка справляется сама. Никаких «неверно».
- **Ноль зависимостей и ноль сборки.** Новая библиотека → сначала подумать, как без неё.
- **Сюжет не выкидываем.** Порядок препятствий и их смысл — из `docs/spec.md`, это каркас игры.

## Грабли
- ES-модули и `fetch` не работают с `file://` — отсюда классические `<script>` и графика кодом.
- **У SVG-элементов нет свойства `hidden`** (оно объявлено на `HTMLElement`). `el.hidden = true`
  молча создаёт обычное поле объекта и ничего не прячет. Только `setAttribute('hidden','')`
  и `removeAttribute`, и правило `[hidden]{display:none!important}` в CSS должно остаться.
- **CSS-трансформ в WAAPI затирает атрибут `transform`.** Если предмет расставлен через
  `transform="translate(x y)"`, анимация `transform` уронит его в начало координат.
  Поэтому каждый анимируемый предмет лежит в обёртке без собственного `transform`.
- `feDisplacementMap` пересчитывается на каждом кадре движения и на всю площадь элемента.
  Вешать его на мир шириной 3000 нельзя; он висит только на улитке.
- Внешний `<svg>` режет по вьюпорту, а не по viewBox: фон и зерно нарисованы с запасом
  за края, иначе при `meet` сверху и снизу остаются пустые полосы.
- Анимация атрибута `r` у `<circle>` через WAAPI работает, но как CSS-свойство, не как атрибут.
- WebAudio стартует только после жеста пользователя — `Sound.wake()` зовётся из `pointerdown`.
